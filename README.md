# 🚢 Titanic Survival Analysis

## 📌 Project Overview

This project performs an end-to-end Exploratory Data Analysis (EDA) on the famous Titanic dataset. The objective is to identify the factors that influenced passenger survival through data cleaning, visualization, statistical analysis, and feature engineering.

Rather than focusing only on creating visualizations, this project emphasizes interpreting the data, identifying meaningful patterns, and documenting analytical insights.

## 📈 Key Insights

Some of the major observations include:

- Female passengers had significantly higher survival rates than male passengers.
- First-class passengers were much more likely to survive compared to third-class passengers.
- Passengers embarking from Cherbourg showed higher survival rates.
- Fare and passenger class exhibited a relationship with survival probability.
- Family characteristics provided additional insight into survival behaviour.
