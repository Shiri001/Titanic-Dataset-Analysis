# Titanic Survival Prediction - Exploratory Data Analysis

## Project Overview
This project explores the Titanic dataset to understand the factors that influenced passenger survival.

## Dataset
- Source: Kaggle Titanic Dataset
- Rows: 891
- Columns: 12 (before cleaning)

## Progress

### Data Cleaning
- Removed Cabin column because of a large number of missing values.
- Filled missing values in Age using the mean.
- Filled missing values in Embarked using the mode.
- Converted suitable columns to categorical data types.

### Exploratory Data Analysis
Completed univariate analysis for:
- Survived
- Passenger Class (Pclass)
- Sex
- SibSp
- Parch
- Embarked
